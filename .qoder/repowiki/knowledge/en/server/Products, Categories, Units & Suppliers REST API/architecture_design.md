Each file defines a single Express `Router` mounted under `/api/{resource}`. All routes are protected by the shared `authenticate` middleware from `../middleware/authenticate.js`, which attaches `req.user`. Mutations (POST/PUT/DELETE) additionally enforce an in-file `requireAdmin` guard that checks `req.user.role === 'Admin'`. Data access goes directly through the shared `pool` from `../db.js` using parameterized `pool.execute` calls; there is no ORM or repository layer. The `products.ts` module is the most complex: it defines a reusable `PRODUCT_COLS` SQL fragment, uses `zod` schemas with `superRefine` for cross-field pricing rules, implements store-generated barcodes via a DB query, and emits audit events through `logAuditEvent` from `../utils/auditLogger.js`. Cross-resource integrity is enforced at the route level (e.g., delete-a-category checks `products.category_id`, delete-a-supplier checks `products.supplier_id`, delete-a-product soft-deletes to `Inactive` when `sale_items` reference exists).
