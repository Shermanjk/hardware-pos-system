Three-file entry layer: `index.html` is the static shell providing the `<div id="root">` mount point and loading `/src/main.tsx` as an ES module. `main.tsx` is the single ReactDOM bootstrap that renders `<App />` into the root node and imports the global stylesheet (`index.css`). `App.tsx` composes the application tree with nested provider wrappers (`ErrorBoundary`, `ThemeProvider`, `AuthProvider`, `TooltipProvider`, `Toaster`) and defines three routing layers built on `wouter`'s `<Switch>`/`<Route>`: a top-level `Router` that separates public routes (`/login`, `/change-password`), a protected Cashier route, a `/clerk/*` subtree routed through `ClerkRouter`, and a catch-all Admin subtree routed through `AdminRouter`. Each sub-router is wrapped in its own layout component (`AdminLayout`, `ClerkLayout`) and gated by `ProtectedRoute` with role checks plus a `PasswordChangeGuard`. Module boundaries are explicit: admin pages live under `./modules/admin/pages`, clerk pages under `./modules/clerk/pages`, and shared cross-cutting concerns (auth, theme, error boundary) under `./shared/`.
